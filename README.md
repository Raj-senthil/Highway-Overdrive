# Highway Overdrive 🏍️💨

An arcade-style 3D Highway Bike Racing game built with **Three.js** and **Web Audio API**. Drive through endless highway traffic at high speeds, manage custom bike physics and multi-speed manual gear shifting, and experience dynamic visual and sound effects directly in the browser with zero external dependencies.

---

## 🌟 Key Features

* **Interactive 3D Showroom**: Custom main menu featuring a rotating 3D showroom stage, high score tracking, and smooth camera transitions into gameplay.
* **Realistic Bike Mechanics & Physics**:
  * Multi-gear dynamic transmission (5-speed sequential gear system).
  * Physics-based steering lean/tilt dynamics, suspension response, and acceleration torque curves.
  * Real-time HUD displaying dynamic Speedometer (KM/H) and Tachometer (RPM).
* **Enhanced Visual Graphics**:
  * PBR metallic shaders, dynamic shadows, atmospheric skybox, and streetlamp lighting.
  * Real-time visual effects: exhaust particle systems, dynamic brake tail-lights, high-speed camera shake, speed blur lines, and asphalt track textures.
* **AI Traffic & Highway Environment**: Dynamic multi-lane traffic (Sedans, SUVs, Trucks) on an endless highway with procedural side strips, guardrails, and overhead gantries.
* **Procedural Web Audio Engine**:
  * Real-time synthesized engine revs scaled to actual RPM and gear state.
  * Custom audio FX for gear shifting, horn, crash impacts, and wind noise.
  * Built-in dynamic Synthwave background music track.
* **Controls & Accessibility**: Full support for Keyboard inputs (`WASD` / Arrow Keys / `E` / `Q` / `Space`) and touch controls for mobile browsers.

## 🎮 How to Play

### Controls
| Action | Keyboard Key | On-Screen Control |
| :--- | :--- | :--- |
| **Steer Left / Right** | `A` / `D` or `Left` / `Right` | Left / Right Touch Buttons |
| **Throttle / Accelerate** | `W` or `Up Arrow` | Gas Pedal Touch Button |
| **Brake / Reverse** | `S` or `Down Arrow` | Brake Pedal Touch Button |
| **Shift Gear Up** | `E` | `GEAR UP` Button |
| **Shift Gear Down** | `Q` | `GEAR DOWN` Button |
| **Honk Horn** | `Spacebar` / `H` | `HORN` Button |
